## Notas técnicas para el prompt a Claude Code
- **Voz:** femenina, delicada, cálida, dicción clara y ritmo pausado — ideal para capacitación institucional (TTS tipo ElevenLabs con voz en español neutro/latino, perfil "cálida/profesional").
- **Colores:** azul institucional BCRP como color principal (headers, recuadros, botones), blanco como fondo, acentos en azul claro o celeste para resaltados. Evitar colores saturados que no correspondan a la marca.
- **Música de fondo:** corporativa suave, volumen bajo, sin competir con la narración.
- **Subtítulos:** simples, en la parte inferior, sincronizados con la narración.
- **Transiciones:** suaves (fade/slide), con recuadros o flechas animadas para guiar la atención sobre cada captura.
- **Formato:** 16:9, 1080p.
- **Imágenes:** ya están organizadas y nombradas por escena en la carpeta `imagenes_datamar/` (escena02 a escena10). Pasarlas junto con este guion a Claude Code.
